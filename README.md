# microsoft/powerplatform-actions

Power Platform Actions Install -- Installs the Power Platform CLI (pac) for use in other actions.  Pulls from nuget.org if arguments are not provided.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/microsoft/powerplatform-actions](https://github.com/microsoft/powerplatform-actions).
